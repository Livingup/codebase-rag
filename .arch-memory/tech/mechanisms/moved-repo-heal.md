# 仓库移动自愈 moved-repo-heal

- 方案：MCP 读路径以客户端传入的当前仓库根目录作为移动信号；自愈的判定与执行归属管理面，复用注册主链完成登记路径更新与漏提交补差。
- 不变量：自愈身份必须以传入仓库根 commit 重新派生的 project_id 为依据，不得采信 .git 缓存文件或客户端声称的路径。
- 不变量：同身份仓库旧登记路径仍存在（复制/双克隆）时不得自动切换登记路径，切换仅限显式注册。
- 不变量：自愈仅恢复既有登记身份，不构成新的注册授权；重启后被剪枝的登记条目可凭随仓库携带的 .git 身份缓存恢复入口。
- 方案：并发自愈按 project_id 合并为单次执行；搜索遇无活跃实例时先同步自愈再重试一次。
